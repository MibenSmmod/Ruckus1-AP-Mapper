Ruckus One AP Mapper

Enter API info to access your R1 account

About

This app requires a RUCKUS One account at https://ruckus.cloud/ and uses APIs to gather data about your network.

This app provides a way to view all access points on a map within a venue, displaying RF information such as Channel, Bandwidth, and Transmit Power. As a bonus, you can see if there are radios disabled.

You can get this information using R1 > Venues > Choose Venue > Overview tab, but you must click each AP to get the data. With high-density floor plans, this app helps you search and find APs or switches by hostname, serial number, MAC address, or IP address quickly.

Written by Mike Rieben, Ruckus Systems Engineer October 2026 and will be provided open source on my github page: https://github.com/MibenSmmod/Ruckus1-AP-Mapper/. Connect with me on LinkedIn: https://www.linkedin.com/in/mikerieben/

How to get your API credentials

Application Token

  1. Navigate to https://ruckus.cloud and login
  2. Menu: Administration > Account Management > Settings
  3. Scroll down to Application Tokens
  4. Click Add Token link (far right)
  5. Enter a name (e.g., "Ruckus One AP Mapper")
  6. Scope: select Read Only (Recommended for viewing). Use Administrator Scope if you need to Edit and move device locations on the map (writes coordinates back to RUCKUS One).
  7. Press Add button
  8. Copy the Client ID and Shared Secret

Tenant ID

Found in two places:

  1. In the URL after logging in
  2. Click your initials (top right) > User Profile > Copy the ID

Query PoE & LLDP from R1

PoE is read from the RUCKUS One cloud API. No SSH session to the access points is opened.

What will happen:
  • Each operational AP is asked to refresh LLDP (the same call the RUCKUS One UI makes; it does not change AP configuration)
  • Negotiated class and allocated power are read from the AP neighbor table
  • The AP is matched to its ICX switch port for PoE type, draw, and budget
  • The map shows negotiated power and live draw on two lines (for example, 802.3bt C5 40.3W / then Using 14.1W)
